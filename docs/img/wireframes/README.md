# Wireframes (step 6.1)

Drawn in Figma: desktop 1440 px and mobile 360 px for each of the six screens.
Greyscale; the risk band is the only colour and always carries its name as text.
Every screen has the footer: "Demo trained on synthetic data. Not for real lending decisions."
